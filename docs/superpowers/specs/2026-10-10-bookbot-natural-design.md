# 书单自然语言发言分析与范围限制

用户要求支持自然语言发言，使用 prompt 限制书籍范围；无关内容固定回复「这是不相关内容」。用户已选择只在 @机器人或引用机器人时回复，其他群聊继续安静记录。本次延续 `codex/bookbot-mvp` 的 `617d6cc`，不配置或连接真实 QQ/DSH。

## 行为与边界

- 显式授权群里，固定命令保持兼容。非命令消息仍记录；只有原事件 @机器人，或网关确认引用的是本账号机器人在本群的消息，才申请自然语言回复。不能相信引用段自称的发送者，不在普通群聊刷拒绝消息。
- 自然语言支持文字与已启用的 QQ 语音转写。当前图片 OCR 可帮助识别所指书名，属于引用材料，不能单独提供用户查询指令。识别结果不能触发撤销或其他写操作。
- prompt 判断意图为 query、record、unrelated、clarify。仅书籍记录、推书、评价、作者、风格、字数、连载状态和群内推书统计属于范围。编程、天气、闲聊、要求绕过规则等内容输出 unrelated，桥接固定回复「这是不相关内容」，不用模型自由回复。
- query 输出严格的受限计划：action、period、title、user、tags、kind。period 支持 all/today/week/seven/yesterday/lastweek；title/user 可空，tags 为短标签数组，kind 为 all/recommend/review/mention。模型不得输出 SQL、群号、账号、来源身份或自由回答。条件不能准确表达、指代不明或需要库外事实时用 clarify；不要悄悄忽略条件。
- 模型仅将自然语言转换为查询。本地绑定账号和群，以参数化 SQLite 同时过滤时间、书名、推荐人和标签，保留来源、时间及图片/语音标记。自然查询展示的讨论记录也遵循相同过滤条件；最新字数/状态与首次推荐另作来源明确的补充信息。昵称重名提示补充 QQ 号；「我」使用真实请求者身份。人数/书数按全部命中记录统计，不用展示条数冒充统计。
- 图书相关但没有记录，说明本群没有相关记录；record 仍进入原有提取，反馈已记录或没有识别到可保存的条目。clarify 使用固定的书籍范围说明，服务错误使用固定暂不可用提示。所有出站走已有 bookbotQuery 审计、静默/模式/权限检查。
- 采用原有持久消息队列，在媒体准备后规划自然请求、完成书籍提取，再基于最新有效库内容回复。消息表增量保存回复申请与经过核实的机器人引用上下文，旧库默认不申请回复。成功完成后不重复回复；发送与数据库之间不承诺跨崩溃的精确一次交付。撤销与非书聊天保留清理同时清除引用上下文。
- 每次规划及最终抽取/回复前检查当前授权、停止状态、来源是否撤销及启用渠道；配置或缓存内容变化使规划不再适用时只延后该消息。DSH 内部各个异步步骤间也检查当前输入，发送审计等待期间撤销查询命中记录会阻止旧结果发出。关闭渠道的待处理缓存不进入规划或上下文；已完成历史与来源继续有效。准备/规划失败只保留原消息等待重试。
- 复用隔离无工具 DSH 会话生命周期，包括模型选择、超时、断流、订阅取消、晚到清理。自然查询不进入通用聊天会话。新增 naturalLanguage 配置默认启用（总书单仍默认禁用）；可关闭自然语言而继续固定命令和记录。

## 验收

离线测试覆盖非固定句式、@及真实机器人引用、普通聊天不回复、无关固定拒绝、文字/语音、OCR不执行、严格计划拒绝 SQL/身份/自由回答、复合查询、昵称歧义、上海昨天/上周边界、来源与真实统计、旧库迁移、错误重试、去重、撤销/关闭渠道/撤权竞态及真实桥接注入。现有 55 项测试继续通过；完整回归与原有 7 项失败基线逐项比较。独立规格审查后做质量审查，仅提交本地分支。
